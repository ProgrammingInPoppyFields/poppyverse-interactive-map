3D Map Pipeline

SRC_clusters.csv + SRC_toc.csv → build_3d_map.py → 3d_map.html. Everything left of the dashed line below runs once, offline, when you re-run the build script. Everything right of it runs fresh in every visitor's browser — and never touches a CSV.

SRC_clusters.csv supplies per-verse color and description; SRC_toc.csv supplies everything per-story, including the already-computed Final X/Final Y/Final Z columns — build_data() reads those as plain numbers rather than deriving a layout formula. Node flags like isIntro, isTrailer, and isMeta are decided the same way the Notion renumbering just was: by pattern-matching the story's Name text at build time.
