# 3d-force-graph fork (unused)

Leftover source and build config from the upstream
[vasturiano/3d-force-graph](https://github.com/vasturiano/3d-force-graph) project
(`src/`, `package.json`, rollup and babel config, lockfiles).

**Nothing in the site uses this.** The 3D maps load the published library from the
unpkg CDN (`3d-force-graph@1.72.0`). Kept only in case the library ever needs to be
built locally; run `npm install && npm run build` from this folder. Safe to delete.
